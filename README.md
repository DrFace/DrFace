# About Me

I'm **Malindu Liyanage**, a software engineer and full-stack developer focused on building practical software products, SaaS platforms, developer tools and business systems.

I am also building **Kentralo**, an independent software and digital product brand focused on creating scalable applications and tools.

My main areas of interest include:

- Full-stack web development
- SaaS architecture
- Multi-tenant systems
- REST APIs and backend systems
- Progressive Web Apps
- Offline-first applications
- Inventory and business management systems
- Cloud infrastructure
- Hosting and server management
- Automation
- Developer tools
- Application security
- AI-assisted software development

I prefer building products that solve actual operational problems rather than creating software purely as technical demonstrations.

# Current Focus

I am currently working on several projects under the **Kentralo** ecosystem.

### Kentralo Inventory SaaS

A scalable multi-tenant inventory and business-management platform designed to support thousands of independent businesses from a single application architecture.

Planned and active areas include:

- Inventory management
- Multi-warehouse support
- Branch management
- Purchase orders
- Sales orders
- Batch tracking
- Expiry tracking
- Restaurant inventory
- Recipe-based ingredient deduction
- Reporting
- Import and export tools
- Role-based permissions
- Multi-language support
- Offline-first PWA functionality
- API integration
- Future POS integration

---

### KenPanel

A unified infrastructure and hosting-management platform.

The long-term goal is to provide a single interface capable of integrating with multiple server and hosting platforms.

Target integrations include:

- cPanel
- Plesk
- DirectAdmin
- aaPanel
- CyberPanel
- CloudPanel
- ISPConfig
- HestiaCP
- Virtualmin
- Webmin
- FASTPANEL
- Easypanel
- Cloudron
- Dokploy
- Coolify
- AWS

The project focuses heavily on API integrations, infrastructure management and simplifying administration across multiple hosting ecosystems.
